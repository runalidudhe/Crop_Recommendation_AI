FAQ

Frequently Asked Questions

Some common questions about contacting and using FarmNexa-AI.

What is FarmNexa-AI? +

FarmNexa-AI is a smart agriculture platform designed to provide AI-based farming assistance and crop recommendation using agricultural and environmental information.

What information is used for crop recommendation? +

The crop recommendation model uses nitrogen, phosphorus, potassium, temperature, humidity, soil pH, and rainfall as its main input parameters.

Can I report a technical problem? +

Yes. Select Technical Support in the subject field and describe the issue clearly in your message.

Can I send suggestions for FarmNexa-AI? +

Yes. Suggestions and feedback are welcome. Select Suggestion / Feedback and tell us what you would like to improve.

What should I include in a technical support message? +

Include the feature or page where the issue occurred, what you expected to happen, and what actually happened.

Where can I use the AI Assistant? +

The AI Assistant is available as a separate page in the FarmNexa-AI navigation so that it can be accessed directly whenever you need it.
